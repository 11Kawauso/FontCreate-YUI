# フォントクリエイト・結

点と点をつないで線を描き、囲んだ中を塗りつぶして、自分だけのフォントを作るWebツールです。

公開ページ: https://11kawauso.github.io/FontCreate-YUI/

## できること

- 線(直線・左右への曲線)、塗りつぶし、定規
- 文字の範囲を広げる透明な線
- 線ごとに消す消しゴムと、接点まで消す消しゴム
- 左右対称・上下対称
- マウス、タッチパッド、指の操作の切り替え
- アルファベット、数字、記号、ひらがな、カタカナの表に1文字ずつ保存
- 背景透過のPNG書き出し、表全体の保存と読み込み
- インストールできるフォントファイル(.otf)の書き出し

描いた内容は使っているブラウザの中に保存されます。サーバーへは送信されません。

## 開発

```bash
npm install
npm run dev
```

`npm test` で計算部分のテスト、`npm run build` で公開用のファイルを作成します。
`main` ブランチに送ると、GitHub Actions で自動的に公開されます。
